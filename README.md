# AI 项目开发规范

版本标识：2026.10.19。面向 AI 辅助开发的独立规范包，覆盖需求、架构、前后端、接口、安全、验证及交付。

## 功能亮点

- 通用规则与可选 Vue、FastAPI、UI 规范样板分离。
- 提供项目配置、初始化清单及五类任务模板。
- 保留工作区保护、真实验证和已授权工作持续执行要求。
- 覆盖 AI 代理指令信任、MCP 权限和上下文共享边界。

## 快速开始

先阅读[接入流程](docs/AI-接入流程.md)，再按[初始化清单](docs/AI-项目初始化清单.md)核实目标仓库，填写[项目配置](项目配置.md)。已有项目必须逐项合并已有规则；禁止直接覆盖。

## 安装说明

解压后按接入流程选择文件并入目标仓库，无须安装依赖。本 README 是包说明，禁止覆盖目标项目产品 README。三个可选规范默认未启用，必须明确登记采用范围。

## 使用示例

“按本项目 AGENTS.md 和已批准的项目配置，先阅读相关代码，分析并完成本次任务；报告实际验证及未验证项。”

## 配置选项

技术栈、路径、检查命令、身份边界、界面设备和错误反馈均由目标项目核实；模板不代表已经实现。测试文件仅本地的包基线与既有项目冲突时，先按合并流程决策。

## 贡献指南

规范变更检查引用、冲突及模板一致性；文件导航见 [FILE_INDEX.md](FILE_INDEX.md)。客户端接入见[接入指南](docs/AI-编程接入指南.md)，安全披露见[安全策略](SECURITY.md)。

联网参考的官方项目、核对日期及采用范围见[工程实践参考](docs/AI-编程工程实践参考.md)。
