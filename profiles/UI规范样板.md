# UI 规范样板

本文件以桌面运维控制台为样例，提供可按目标项目配置选用的 UI 规范；设备范围、技术栈及错误反馈仍按下述启用边界执行。

## 启用与边界

仅当 [项目配置](../项目配置.md) 明确启用本 profile，批准桌面运维控制台的视觉、交互和验收范围，且项目确实具有对应业务界面时生效。文件存在不等于启用，不授权改版、换色、增加主题、创建全部下述组件或改变项目既有错误反馈。未启用时只执行[通用前端开发约束规范](../docs/AI-前端开发约束规范.md)及目标项目已批准的设计约定；已有项目政策与本 profile 冲突时按主规范澄清，不直接覆盖。下述状态组件、业务测试和技术细节只在需求与目标项目配置适用时实施。

本 profile 的“仅桌面大窗口，不做中、小窗口或移动端适配”只在项目配置明确批准此设备/视口范围时适用；目标项目另有移动端或中小视口要求时，不能据此删除或忽略。适用桌面范围内不得自行添加响应式断点、移动导航抽屉、按窗口宽度重排布局或将多列表单改为单列；窗口缩小时保持已批准的桌面结构。

## 最小必要信息

- 所有页面、弹窗、表格、表单、tooltip、消息和导出展示都应服务明确用户任务。新增内容要说明帮助谁理解何种状态、完成何种判断或操作；禁止因接口返回字段就直接铺完整 JSON、内部配置、协议术语或调试信息。
- 关键结果、影响范围、必要状态、校验要求和危险操作确认保持可见。加载、失败、空数据和未完成状态如实区分，不能以精简为由伪造成功或掩盖风险。
- 有实际用途但低频查阅的明细、原始业务证据和高级选项按需展开；无用途内容删除，不藏入 tooltip。运维对象的路径、命令和日志若为必要证据，可在有权限的详情保留。
- 文案简短具体，避免重复标题、装饰性欢迎语及无行动价值的提示；精简内容时保留字段标签、可访问名称和键盘入口。无消费用途的响应字段需联动服务端核对，前端隐藏不等于服务端过滤。

## 视觉与布局

- 采用紧凑运维控制台布局，以蓝色主操作、石墨色顶栏、中性灰背景和浅色面板建立视觉层级。
- 顶栏高 40px，背景 `--ui-header-bg`、文字 `--ui-header-text`；品牌使用目标项目在配置中登记的名称与标识。主导航展开宽 200px、收起宽 54px，菜单项高 38px。
- 导航选中项使用主色文字和左侧 3px 指示条；主导航与页面分组筛选区分。内容区占满剩余宽度，背景 `--ui-canvas`，内边距 20px，不以居中窄容器制造大面积留白。
- 页面按“面包屑、紧凑标题、工具栏、数据区”组织，列表页以表格为核心。固定顶栏只预留一次高度，各区域明确滚动容器，避免重复偏移、内容裁切和整页横向溢出。
- 模块间距 16px，控件间距 8px；输入控件直角，小按钮圆角 2px，表格顶部可用 5px 圆角。普通面板用背景与细边框分层，浮层可有轻微阴影；不增加无业务用途的欢迎横幅、巨型标题、装饰卡片、渐变、玻璃效果和大圆角。

## 颜色

下表为本样板的浅色主题候选值，仅在配置中批准采用时作为目标项目变量值；不宣称目标项目独立原创，也不据此复制其他产品品牌色板。统一从 CSS 自定义属性引用，不在页面散落硬编码颜色；不得自行增加新主题。蓝色表示主操作与信息、红色表示危险、绿色表示成功、琥珀色表示警告，中性灰用于背景和次要操作，不能只靠颜色表达状态。

- 主色用于主要操作、真实链接与导航选中，不铺满内容区。同一操作区域只保留一个高强调主操作；刷新、取消用中性按钮，删除用危险色，禁用状态使用专用变量而非全组件降低 opacity。
- 状态标签使用对应浅底、深色前景和状态文字或可访问名称。删除默认为危险色文字，hover 用危险浅底，实心危险按钮配白字；错误输入框边界用危险色。
- 键盘焦点使用主色 2px 外轮廓、偏移 2px；深色顶栏用 `--ui-header-text`。正文与背景对比度至少 4.5:1，控件边界和焦点与相邻背景至少 3:1；调整色板后重算实际主按钮白字、顶栏、辅助文字、状态底色和透明叠加的组合。
- **仅在 [Vue 3 前端技术栈规范](Vue3前端技术栈规范.md) 已启用且目标项目实际使用 Element Plus 时**，映射 `--el-color-primary` 和 `dark-2` 至主色与 hover，显式设置按下态，并映射 success/info/warning/danger、背景、文字、placeholder、控件边框和传送到 body 的浮层。组件库需要 `light-3/5/7/8/9` 时按基础色与白色的 30%/50%/70%/80%/90% 白色占比在 sRGB 通道混合；交互浅底优先使用上表变量。其他 UI 框架不套用 Element Plus API。

## 字体、表格与分页

- 使用系统字体栈 `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`，不新增字体下载依赖。正文 13px、行高约 1.43；辅助信息 12px、行高 18px；页面标题 18px / 600，分区标题 14px / 600，弹窗标题 16px，菜单文字 12px。长名称、地址及说明必须能查看完整内容。
- 工具栏主要操作放左，搜索、筛选和刷新放右，控件高度一致。表格文字 13px、行高 1.5；表头纵向内边距 8px，正文单元格 6px；表头用 `--ui-surface-muted`，正文用 `--ui-surface`，横向分隔线用 `--ui-border`，常规单元格不加纵向网格。
- 单行目标高度约 36–40px，双行自然增高；行 hover 使用 `--ui-row-hover`、选中使用 `--ui-primary-soft`，操作列放右侧，宽表必要时固定操作列并在表格容器内横向滚动。名称仅在有真实跳转时用链接样式。分组栏宽 220px，平面分组用列表不伪造层级树。统计、在线状态、批量操作仅在业务与数据支持时展示。
- 启用此 profile 的列表页提供分页和每页 10、20、50 条的选项，支持页码切换；当前展示数据与页码、页长一致。页长或搜索筛选条件变化时重置第一页，使用真实总数与数据，复用已有分页能力，不用备用数据掩盖失败。

## 测试状态展示

以下适用于目标项目确实存在检测流程与结果状态的界面；不要求为不存在的业务创建组件。复用[项目配置](../项目配置.md)登记的状态展示组件、状态类型和同类业务的映射函数；名称与位置从实际源码核实，不预设组件或工具文件名。

- 若采用此视觉约定，统一使用 18px 圆形轮廓图标：`passed` 绿色勾、`failed` 红色叉、`pending` 蓝色省略号、`warning` 琥珀色感叹号、`untested` 和 `unavailable` 灰色问号，色值使用语义变量，不单靠颜色区分。
- 图标提供中文 tooltip 及同义可访问名称，说明测试对象、当前状态和已知使用限制；未测试、排队、测试中、已中断、待确认及状态待刷新分别表达。请求错误交由已批准的统一反馈入口，不在 tooltip 推测原因。
- 独立图标可 Tab 聚焦并有可见焦点，鼠标悬停和键盘聚焦都能查看提示；放在已有可聚焦按钮内时不增加重复 Tab 停靠点，沿用父按钮焦点显示提示并在失焦时恢复。
- 共用组件只承担图标、语义颜色、tooltip 与可访问性；业务组件处理请求、轮询、状态映射和文案，多处同类业务复用映射规则。合并多项检测时，仅全部必需项通过才显示通过并开放依赖功能，失败不能显示通过，未完成不算通过，进行中的测试优先显示测试中。
- 必需检测项和启用条件由目标业务契约定义，禁止预设具体检测类型。测试历史、批量测试和详情仅在实际存在时复用状态组件，必要详情与失败说明仍留在业务页面。

## 按钮、表单与展开详情

- 常规按钮高 30px、字号 13px、内边距 8px 12px、圆角 2px；主动作主色实心，次要动作中性描边，行内紧凑文字，删除危险色。输入、选择、数字输入等常规控件高 30px、字号 13px、圆角 0，多选可自然增高。控件单层边框，聚焦主色、错误危险色。
- 表单按业务分区，字段间距 20px，短字段可排两列，适用桌面范围内不随宽度改列数。标签与控件关联，必填标识用 `--ui-danger`，placeholder 不替代标签；图标按钮须有可访问名称。
- Disclosure 是点击后在当前页面显示或隐藏详情的控件，多个相关分区用 Accordion；只折叠按需查阅的内容，错误等级、名称、影响范围、原因与建议等核心信息保持可见。禁止折叠面板嵌套、用跳转链接冒充按钮。
- 展开入口默认就可辨认为控件，不能只靠 hover、颜色或 tooltip。单项入口为紧凑中性描边按钮：高 30px、字号 13px、水平内边距 12px、圆角 2px，使用 `--ui-surface`、`--ui-text` 与 `--ui-control-border`。分组标题整行可点击，高至少 36px、水平内边距 12px、标题 13px / 600，背景 `--ui-surface-muted`、分隔线 `--ui-border`。
- 箭头位于标题左侧，相距 8px、尺寸 14px，收起朝右、展开朝下；同一点击区域同时包含箭头、标题和展开/收起文案。单项可用“展开相关报错详情”与“收起相关报错详情”，分组标题保留名称和动作，不能只写“更多”或“详情”。数量来自真实数据并标明单位。hover 用 `--ui-row-hover`，按下用 `--ui-surface-muted`，焦点外轮廓 2px、偏移 2px。
- 展开内容紧随入口并保留收起入口；隐藏内容内部控件不留在 Tab 顺序。若在内容内触发收起，把焦点返回入口。控件支持 Tab / Shift+Tab、Enter 和 Space；自定义优先用 `type="button"`，`aria-expanded` 与实际可见状态同步，`aria-controls` 关联唯一容器 ID，可访问名称说明对象，装饰箭头对辅助技术隐藏。展开不自动跳转或移动焦点，无详情不显示可操作入口，异步失败不伪装为空数据。
- 仅当 Vue/Element Plus profile 已启用且项目实际使用时，优先复用已有 `ElCollapse` / `ElCollapseItem` 或 `ElButton`；定制标题沿用现有状态，不在按钮内嵌按钮。其他框架复用其现有组件或原生语义控件，不套用 Element Plus API。

## 弹窗、错误与状态

- 弹窗在视口内居中，标题 16px、页脚按“取消、保存”排列；简单表单约 440px，复杂表单约 720px，不超视口，长内容可滚动且操作始终可达。区分加载中、无数据、无结果、加载失败、字段错误与保存中；保存中阻止重复提交，请求失败恢复本地交互状态并保留未保存表单，不推断服务端已回滚，危险确认说明对象与影响。
- 以下“系统异常”统一请求错误文案、顶部居中消息距顶 16px、3000ms 自动关闭、同类可见消息去重，仅是启用本 profile **且由项目配置登记批准**的反馈选项；必须与目标项目既有错误政策一致。已有错误契约不一致时按主规范澄清，不借 profile 改写或遮蔽错误处理。
- 在该选项适用时，本地必填、格式、大小校验可以在字段附近显示具体原因；后端接口、网络、超时、响应读取及 JSON 解析失败由请求层转换明确错误类型并抛出，页面经共用反馈入口显示“系统异常”，不展示、改写后端详情或据状态码猜测原因。请求层不自行弹窗，不吞异常或返回默认数据。
- 共用入口集中维护文案、位置、样式、时长和同类错误合并；消息可见期间只显示一条，不显示重复次数，消失后可重新提示。仅在 Vue/Element Plus profile 已启用且项目实际使用时可以使用 `ElMessage`；其他框架沿用自己的统一反馈实现。
- 用布尔值、枚举等独立业务状态表达失败，不能用文案赋值或比较判断业务状态。列表、详情、保存、删除分别管理状态；保存/删除失败不标记列表加载失败，成功后重载列表失败才改变列表失败状态。过期请求不能改写状态或弹消息。失败不能显示正常空态或关闭未保存表单，重试成功恢复数据展示；不得添加未获批的失败兜底。

## 桌面验收与来源边界

- 仅在项目配置批准桌面范围时，保持侧栏、分组栏与表格固定结构，侧栏只由用户操作收放；宽表在自身容器滚动，确保弹窗、下拉与操作可达。保留可见键盘焦点、合理的弹窗焦点进入与返回，以及文字、控件边界和背景对比度。
- 核对色板、布局、字体、尺寸、分页的 10/20/50 切换与页码重置；覆盖加载、空数据、错误、保存中、长文本和长表单。逐项检查字段、提示、tooltip 和详情的用户用途，不直接暴露原始对象或内部调试信息。
- Disclosure 验收覆盖默认、hover、聚焦、展开、收起与无详情：箭头紧邻文字，整块可点，Enter / Space 有效，文案、箭头、`aria-expanded` 与可见性一致，`aria-controls` 指向唯一容器；收起后内部不可 Tab 聚焦。
- 在已批准的消息选项适用时，核对并发同类错误只提示一次、过期请求无消息、失败不显示正常空态、重试成功恢复、保存失败保留表单、本地校验与请求错误分离。验证命令须来自目标项目真实配置；具备浏览器条件时在 1440px 桌面窗口检查布局及交互，未执行项如实说明，不因此自动扩大到其他设备范围。

本 profile 保留可选桌面样板的布局与视觉约定，外部引用仅提供设计原则、语义及可访问性依据，不要求复刻其他产品色板或默认安装其组件。以下资料的历史核对日期为 2026-10-14；2026-10-19 的工程资料调研未逐条复核其当前内容，不将历史记录称为本次新验证：

- 配色依据：[Atlassian 颜色角色与交互状态](https://atlassian.design/foundations/color)、[Carbon 主操作与危险按钮](https://carbondesignsystem.com/components/button/usage/)、[W3C WCAG 颜色不能作为唯一提示](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)，借鉴语义和层级，不复制其品牌色板。
- 即时反馈参考：[Element Plus Message](https://element-plus.org/en-US/component/message)，仅供采用 Element Plus 且批准上述反馈方式的项目使用。
- 最小必要信息依据：[Nielsen 美观与极简设计](https://www.nngroup.com/articles/aesthetic-minimalist-design/)、[Nielsen 渐进式披露](https://www.nngroup.com/articles/progressive-disclosure/)、[Nielsen 信息污染](https://www.nngroup.com/articles/information-pollution/)，保留完成任务所需内容，次要内容按需查阅。
- 展开交互依据：[W3C WAI-ARIA Disclosure 模式](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)、[GOV.UK Details](https://design-system.service.gov.uk/components/details/)、[GOV.UK Accordion](https://design-system.service.gov.uk/components/accordion/)；[Element Plus Collapse](https://element-plus.org/en-US/component/collapse.html) 只提供已启用框架下的组件选项，不取代目标项目已有组件。
